# 🔧 Решение проблемы: домен работает на мобильном, но не на десктопе

## Проблема
Домен `resumio.ru` работает на мобильном устройстве, но не работает на десктопе.

## Причины

### 1. Кэш DNS на десктопе
DNS кэш на компьютере может содержать старые записи или неработающие адреса.

### 2. Кэш браузера
Браузер может кэшировать старую версию сайта или ошибки подключения.

### 3. Проблемы с DNS провайдером
Ваш интернет-провайдер на десктопе может использовать другие DNS серверы, которые еще не обновились.

---

## Решения (по порядку)

### Решение 1: Очистить кэш DNS на десктопе

#### macOS:
```bash
sudo dscacheutil -flushcache
sudo killall -HUP mDNSResponder
```

#### Windows:
```bash
ipconfig /flushdns
```

#### Linux:
```bash
sudo systemd-resolve --flush-caches
# или
sudo service network-manager restart
```

**После очистки:**
- Перезапустите браузер
- Попробуйте открыть `https://resumio.ru` снова

---

### Решение 2: Очистить кэш браузера

#### Chrome/Edge:
1. Нажмите `Cmd+Shift+Delete` (Mac) или `Ctrl+Shift+Delete` (Windows)
2. Выберите "Все время"
3. Отметьте "Изображения и файлы в кэше"
4. Нажмите "Удалить данные"

#### Safari:
1. Нажмите `Cmd+Option+E` (очистить кэш)
2. Или Safari → Настройки → Дополнения → Разработка → Очистить кэш

#### Firefox:
1. Нажмите `Cmd+Shift+Delete` (Mac) или `Ctrl+Shift+Delete` (Windows)
2. Выберите "Все"
3. Отметьте "Кэш"
4. Нажмите "Удалить сейчас"

---

### Решение 3: Использовать другой DNS сервер

Если ваш провайдер использует медленные DNS серверы:

#### Изменить DNS на компьютере:

**macOS:**
1. Системные настройки → Сеть
2. Выберите ваше подключение → Дополнительно → DNS
3. Добавьте DNS серверы:
   - `8.8.8.8` (Google)
   - `1.1.1.1` (Cloudflare)
4. Сохраните

**Windows:**
1. Панель управления → Сеть и Интернет → Центр управления сетями
2. Изменение параметров адаптера
3. Правый клик на ваше подключение → Свойства
4. Протокол Интернета версии 4 (TCP/IPv4) → Свойства
5. Использовать следующие адреса DNS:
   - `8.8.8.8`
   - `1.1.1.1`
6. Сохраните

**После изменения DNS:**
- Перезапустите браузер
- Очистите кэш DNS (см. Решение 1)
- Попробуйте открыть сайт снова

---

### Решение 4: Проверить через другой браузер

Попробуйте открыть `https://resumio.ru` в другом браузере:
- Если в другом браузере работает → проблема в кэше первого браузера
- Если не работает → проблема в DNS/сети

---

### Решение 5: Использовать режим инкогнито

Откройте сайт в режиме инкогнито/приватном режиме:
- Chrome: `Cmd+Shift+N` (Mac) или `Ctrl+Shift+N` (Windows)
- Safari: `Cmd+Shift+N`
- Firefox: `Cmd+Shift+P` (Mac) или `Ctrl+Shift+P` (Windows)

Если в режиме инкогнито работает → проблема в кэше браузера.

---

## Быстрая диагностика

### Проверьте DNS записи на десктопе:

**macOS/Linux:**
```bash
dig resumio.ru A
nslookup resumio.ru
```

**Windows:**
```cmd
nslookup resumio.ru
```

**Ожидаемый результат:**
- Должен вернуть IP: `216.198.79.1`
- Если возвращает другой IP или ошибку → проблема в DNS

---

## Рекомендуемый порядок действий

1. **Очистите кэш DNS** (Решение 1)
2. **Очистите кэш браузера** (Решение 2)
3. **Попробуйте в режиме инкогнито** (Решение 5)
4. **Если не помогло** → измените DNS сервер (Решение 3)

---

## Если ничего не помогло

1. Перезагрузите компьютер
2. Проверьте, не блокирует ли антивирус/файрвол сайт
3. Попробуйте через VPN
4. Используйте `www.resumio.ru` вместо `resumio.ru`

---

**Начните с очистки кэша DNS и браузера - это решает 90% таких проблем!**
