# 🔍 Как проверить что RLS включен

## Пошаговая инструкция:

### Шаг 1: Откройте новый запрос

В SQL Editor нажмите кнопку **"+"** (справа от вкладки "Resumes row-level access controls")

Или просто создайте новую вкладку.

---

### Шаг 2: Вставьте проверочный SQL код

Скопируйте и вставьте этот код в редактор:

```sql
SELECT 
  tablename, 
  rowsecurity as "RLS включен"
FROM pg_tables 
WHERE tablename = 'resumes';
```

---

### Шаг 3: Нажмите "Run"

Нажмите зеленую кнопку **"Run"** (внизу справа, с иконкой ▶️)

---

### Шаг 4: Проверьте результат

В панели "Results" (внизу) должно появиться:

```
tablename | RLS включен
----------+-------------
resumes   | true
```

**Если видите `true` - значит RLS включен! ✅**

---

## Дополнительная проверка (опционально)

Если хотите увидеть все политики, выполните:

```sql
SELECT 
  policyname as "Название политики",
  cmd as "Операция"
FROM pg_policies 
WHERE tablename = 'resumes';
```

Должно быть 4 политики (SELECT, INSERT, UPDATE, DELETE).

---

## Кратко:

1. Нажмите **"+"** (создать новый запрос)
2. Вставьте SQL код
3. Нажмите **"Run"**
4. Проверьте результат

Готово! 🚀
