# 🔍 Отладка Sentry

## Проблема
`window.Sentry` возвращает `undefined`

## Возможные причины

### 1. DSN не настроен
**Проверка:**
В консоли браузера выполните:
```javascript
// Это не сработает в браузере, но можно проверить через Network
// Или проверьте файл .env.local
```

**Решение:**
Убедитесь что в `.env.local` есть:
```env
NEXT_PUBLIC_SENTRY_DSN=https://ваш-dsn-из-sentry
```

---

### 2. Сервер не перезапущен после изменений
**Решение:**
1. Остановите сервер (Ctrl+C)
2. Запустите снова: `npm run dev`
3. Обновите страницу

---

### 3. Sentry не инициализируется
**Проверка:**
В консоли браузера выполните:
```javascript
// Проверьте что компонент SentryInit загружен
console.log(document.querySelector('[data-sentry-init]'));
```

---

## Альтернативный способ тестирования

Если Sentry не работает в консоли, можно протестировать через реальную ошибку:

1. Откройте страницу создания резюме
2. Попробуйте скачать PDF с невалидными данными
3. Если будет ошибка — Sentry зафиксирует её автоматически

Или создайте тестовую ошибку в коде:
- Откройте любую страницу
- В консоли выполните: `throw new Error("Test error")`
- Sentry должен зафиксировать это автоматически

---

## Проверка что Sentry работает

### Способ 1: Проверить Network запросы
1. Откройте консоль → вкладка "Network" (Сеть)
2. Обновите страницу
3. Найдите запросы к `sentry.io` или `ingest.sentry.io`
4. Если запросы есть — Sentry работает

### Способ 2: Проверить в Sentry Dashboard
1. Откройте https://sentry.io
2. Перейдите в **Issues**
3. Если есть события — Sentry работает

---

## Если ничего не помогает

Sentry может работать даже если `window.Sentry` недоступен. Главное — он фиксирует ошибки автоматически.

**Для тестирования алертов:**
1. Создайте реальную ошибку (например, попробуйте скачать PDF с пустыми данными)
2. Проверьте Sentry Dashboard — должно появиться событие
3. Проверьте email — должно прийти уведомление

---

**Важно:** Алерты будут работать даже если `window.Sentry` недоступен в консоли. Sentry автоматически фиксирует все ошибки в приложении.
