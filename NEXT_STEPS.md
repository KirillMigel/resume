### 2. Настроить кастомный домен (опционально, 15-30 мин)

**Текущий URL:** `https://resume1-ten.vercel.app`

**Зачем нужен кастомный домен:**
- ✅ Более профессиональный вид
- ✅ Лучше для SEO
- ✅ Легче запомнить
- ✅ Можно использовать для email

**Как настроить:**

#### Вариант 1: Бесплатный домен от Vercel

1. В Vercel Dashboard → Settings → Domains
2. Добавьте домен (например: `resumio.vercel.app`)
3. Готово! (автоматически)

#### Вариант 2: Купить домен (рекомендуется)

**Где купить:**
- **Namecheap** (от $8.88/год) - популярный выбор
- **GoDaddy** (от $12.99/год)
- **Cloudflare** (от $8.57/год) - дешевле + бесплатный SSL
- **Reg.ru** (от 199₽/год) - для .ru доменов

**Рекомендуемые домены:**
- `resumio.ru` / `resumio.com`
- `resume-builder.ru` / `resume-builder.com`
- `myresume.ru` / `myresume.com`

**После покупки:**
1. В Vercel Dashboard → Settings → Domains
2. Добавьте ваш домен
3. Настройте DNS записи (CNAME на `cname.vercel-dns.com`)
4. Подождите 24-48 часов для активации

**Инструкция:** Vercel автоматически покажет какие DNS записи добавить.
