### 2. Протестировать основные сценарии (10 мин)

- [ ] Экспорт PDF
- [ ] Сохранение в дашборде
- [ ] Удаление резюме

### 3. Проверить сборку (2 мин)
```bash
cd resume-builder
npm run build
```
Должно пройти без ошибок.

### 4. Проверить health check (1 мин)
```bash
npm run dev
curl http://localhost:3000/api/health
```
Должно вернуть `{"status": "healthy"}`

## 🔧 Настройка домена (опционально)

### Если хотите использовать свой домен:

1. **В Vercel Dashboard → Settings → Domains**
2. **Добавьте домен:**
   - Введите ваш домен (например: `resumio.ru`)
3. **Настройте DNS:**
   - Добавьте CNAME запись в DNS вашего домена
   - Укажите на `cname.vercel-dns.com`
4. **Дождитесь подтверждения** (может занять до 24 часов)
