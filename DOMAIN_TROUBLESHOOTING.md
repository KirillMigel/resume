# 🔧 Решение проблем с доменом resumio.ru

## Проблема: Домен не загружается или долго грузит

---

## 🔍 Причины и решения

### 1. DNS записи еще не распространились

**Симптомы:**
- Домен долго грузит
- Страница не открывается
- Таймаут соединения

**Решение:**
- Подождите еще 30-60 минут
- DNS изменения могут занять до 2 часов

**Проверка:**
```bash
# Проверить DNS записи
dig resumio.ru A
dig www.resumio.ru CNAME
```

---

### 2. Не добавлена запись для основного домена (resumio.ru без www)

**Симптомы:**
- `www.resumio.ru` работает, но `resumio.ru` не работает
- Или наоборот

**Решение:**
1. Проверьте в Vercel, есть ли домен `resumio.ru` (без www)
2. Если есть - добавьте DNS запись в Selectel:
   - Имя: `@` или оставьте пустым
   - Тип: CNAME или A (как показал Vercel)
   - Значение: скопируйте из Vercel

---

### 3. Неправильно настроены DNS записи

**Симптомы:**
- Домен не открывается
- Ошибка "DNS_PROBE_FINISHED_NXDOMAIN"

**Решение:**
1. Проверьте в Selectel:
   - Имя записи правильное (`www` или `@`)
   - Значение правильное (скопировано из Vercel)
   - Тип записи правильный (CNAME)

2. Проверьте в Vercel:
   - Статус домена должен быть "Valid Configuration"
   - Если "Invalid Configuration" - проверьте DNS записи

---

### 4. Зона не делегирована

**Симптомы:**
- Предупреждение в Selectel "Зона не делегирована"
- DNS записи не работают

**Решение:**
1. В Selectel нужно указать NS серверы у регистратора
2. Но для работы с Vercel это не обязательно
3. Главное - правильно добавить CNAME записи

---

## ✅ Пошаговая проверка

### Шаг 1: Проверить DNS записи через командную строку

```bash
# Проверить основной домен
dig resumio.ru A

# Проверить www поддомен
dig www.resumio.ru CNAME

# Или через nslookup
nslookup resumio.ru
nslookup www.resumio.ru
```

**Ожидаемый результат:**
- Для `www.resumio.ru` должен быть CNAME на `5ee4777a7e28c224.vercel-dns-017.com.`
- Для `resumio.ru` должен быть A запись или CNAME (зависит от Vercel)

---

### Шаг 2: Проверить статус в Vercel

1. Откройте Vercel Dashboard
2. Settings → Domains
3. Проверьте статус:
   - ✅ "Valid Configuration" - все правильно
   - ⚠️ "Invalid Configuration" - проверьте DNS записи
   - ⏳ "Pending" - подождите еще

---

### Шаг 3: Проверить DNS записи в Selectel

1. Откройте Selectel → DNS → Доменные зоны → resumio.ru
2. Проверьте что есть запись:
   - Имя: `www`
   - Тип: `CNAME`
   - Значение: `5ee4777a7e28c224.vercel-dns-017.com.`

---

### Шаг 4: Добавить запись для основного домена (если нужно)

Если в Vercel есть домен `resumio.ru` (без www):

1. Откройте его в Vercel
2. Скопируйте DNS запись
3. Добавьте в Selectel:
   - Имя: `@` или оставьте пустым
   - Тип: как показал Vercel (обычно CNAME)
   - Значение: скопируйте из Vercel

---

## 🚨 Быстрое решение

### Если домен не работает:

1. **Проверьте в Vercel:**
   - Есть ли домен `resumio.ru` (без www)?
   - Какой статус у доменов?

2. **Проверьте в Selectel:**
   - Есть ли запись для `www`?
   - Есть ли запись для `@` (основной домен)?

3. **Подождите:**
   - DNS изменения могут занять до 2 часов
   - Попробуйте через 1-2 часа

4. **Очистите кэш DNS:**
   ```bash
   # macOS
   sudo dscacheutil -flushcache
   
   # Windows
   ipconfig /flushdns
   ```

---

## 📞 Если ничего не помогает

1. Проверьте статус в Vercel - должен быть "Valid Configuration"
2. Проверьте DNS записи через `dig` или `nslookup`
3. Подождите еще 1-2 часа
4. Если все равно не работает - напишите, разберемся
