# Проверка бэкапов Supabase

## Шаг 1: Откройте Supabase Dashboard

1. Перейдите на https://app.supabase.com
2. Войдите в свой аккаунт
3. Выберите проект Resumio

## Шаг 2: Проверьте настройки бэкапов

1. В левом меню перейдите в **Settings** → **Database**
2. Прокрутите до раздела **Backups**

## Шаг 3: Проверьте статус бэкапов

### Для Free Tier:
- Автоматические ежедневные бэкапы включены по умолчанию
- Хранятся 7 дней
- Проверьте что статус показывает "Active"

### Для Paid Tier:
- Можно настроить более частые бэкапы
- Можно настроить более длительное хранение

## Шаг 4: (Опционально) Протестируйте восстановление

Если хотите убедиться что бэкапы работают:

1. В Supabase Dashboard → Database → Backups
2. Выберите точку восстановления
3. Создайте тестовый проект и восстановите в него
4. Проверьте что данные восстановились корректно

## Важно

- Бэкапы автоматические, но их нужно периодически проверять
- Рекомендуется делать ручные бэкапы перед важными миграциями
- Документируйте процесс восстановления

## Готово! ✅

Если бэкапы активны - всё в порядке. Если нет - включите их в настройках.
