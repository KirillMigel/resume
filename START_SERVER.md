# 🚀 Как запустить dev сервер

## Если сервер не запущен:

### Вариант 1: Запустить в терминале

1. Откройте терминал
2. Перейдите в папку проекта:
   ```bash
   cd "/Users/kirillmigel/Desktop/Resume 2/resume-builder"
   ```
3. Запустите сервер:
   ```bash
   npm run dev
   ```
4. Дождитесь сообщения:
   ```
   ✓ Ready in X seconds
   ○ Local: http://localhost:3000
   ```
5. Откройте http://localhost:3000 в браузере

---

## Если сервер уже запущен, но страница не открывается:

### Проверка 1: Правильный адрес
Убедитесь что открываете: **http://localhost:3000** (не https://)

### Проверка 2: Очистить кеш браузера
- Chrome/Edge: Ctrl+Shift+Delete (Cmd+Shift+Delete на Mac)
- Выберите "Очистить кеш"
- Попробуйте снова

### Проверка 3: Проверить ошибки в консоли
1. Откройте консоль разработчика (F12)
2. Посмотрите на вкладку "Console"
3. Есть ли красные ошибки? Пришлите их мне

### Проверка 4: Проверить логи сервера
В терминале где запущен `npm run dev` посмотрите:
- Есть ли ошибки?
- Что показывает сервер?

---

## Если ничего не помогает:

1. Остановите сервер (Ctrl+C в терминале)
2. Очистите кеш:
   ```bash
   rm -rf .next
   ```
3. Перезапустите:
   ```bash
   npm run dev
   ```

---

**Что именно не открывается?**
- Главная страница (localhost:3000)?
- Конкретная страница?
- Вообще ничего не загружается?

Пришлите скриншот или опишите что видите.
