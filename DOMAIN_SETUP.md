# 🌐 Настройка домена resumio.ru для Vercel

**Домен:** resumio.ru  
**Регистратор:** Selectel  
**Хостинг:** Vercel

---

## 📋 Пошаговая инструкция

### Шаг 1: Добавить домен в Vercel (5 минут)

1. **Откройте Vercel Dashboard:**
   - Перейдите на https://vercel.com/dashboard
   - Выберите проект **resume1**

2. **Перейдите в Settings → Domains:**
   - В меню проекта нажмите **Settings**
   - Выберите вкладку **Domains**

3. **Добавьте домен:**
   - Нажмите **"Add Domain"** или **"Add"**
   - Введите: `resumio.ru`
   - Нажмите **"Add"**

4. **Vercel покажет DNS записи:**
   - После добавления Vercel покажет какие DNS записи нужно добавить
   - Обычно это:
     - **A запись** или **CNAME запись**
     - Значение будет что-то вроде: `cname.vercel-dns.com` или IP адрес

**Важно:** Запишите эти значения, они понадобятся в следующем шаге!

---

### Шаг 2: Настроить DNS записи в Selectel (10 минут)

1. **Откройте Selectel DNS:**
   - Перейдите в https://panel.selectel.com
   - Войдите в аккаунт
   - Перейдите в **DNS → Домены → resumio.ru**

2. **Подтвердите номер телефона (если нужно):**
   - Если видите предупреждение "Для делегирования домена подтвердите номер телефона"
   - Нажмите на предупреждение и подтвердите номер

3. **Добавьте DNS записи:**
   
   **Вариант A: Если Vercel показал CNAME запись:**
   
   - Нажмите **"Добавить запись"** или **"Add Record"**
   - Тип записи: **CNAME**
   - Имя/Поддомен: `@` (для корневого домена) или оставьте пустым
   - Значение: `cname.vercel-dns.com` (или то, что показал Vercel)
   - TTL: `3600` (или по умолчанию)
   - Нажмите **"Сохранить"**

   **Вариант B: Если Vercel показал A запись:**
   
   - Нажмите **"Добавить запись"**
   - Тип записи: **A**
   - Имя/Поддомен: `@` (для корневого домена)
   - Значение: IP адрес (например: `76.76.21.21` - это пример, используйте то, что показал Vercel)
   - TTL: `3600`
   - Нажмите **"Сохранить"**

4. **Добавьте запись для www (опционально, но рекомендуется):**
   - Тип записи: **CNAME**
   - Имя/Поддомен: `www`
   - Значение: `cname.vercel-dns.com` (или то, что показал Vercel)
   - TTL: `3600`
   - Нажмите **"Сохранить"**

---

### Шаг 3: Проверить настройки в Vercel (2 минуты)

1. **Вернитесь в Vercel Dashboard:**
   - Перейдите в **Settings → Domains**
   - Найдите домен `resumio.ru`

2. **Проверьте статус:**
   - Статус должен быть **"Valid Configuration"** или **"Pending"**
   - Если статус **"Invalid Configuration"** - проверьте DNS записи

3. **Дождитесь активации:**
   - DNS изменения могут занять от 5 минут до 48 часов
   - Обычно активируется в течение 1-2 часов

---

### Шаг 4: Проверить работу домена (после активации)

1. **Проверьте доступность:**
   - Откройте в браузере: `https://resumio.ru`
   - Должна открыться ваша главная страница

2. **Проверьте SSL сертификат:**
   - Vercel автоматически выдаст SSL сертификат
   - Должен работать HTTPS

## ⚠️ Важные моменты

### 1. Подтверждение номера телефона

Если видите предупреждение в Selectel:
- Нажмите на предупреждение
- Подтвердите номер телефона
- Это нужно для делегирования домена

### 2. Время активации DNS

- **Минимум:** 5-15 минут
- **Обычно:** 1-2 часа
- **Максимум:** 24-48 часов

### 3. Проверка DNS записей

Можно проверить через командную строку:
```bash
# Проверить A запись
dig resumio.ru A

# Проверить CNAME запись
dig resumio.ru CNAME

# Или через nslookup
nslookup resumio.ru
```

## 🔧 Если что-то не работает

### Проблема: Домен не активируется

**Решение:**
1. Проверьте DNS записи в Selectel
2. Убедитесь что значения правильные (скопированы из Vercel)
3. Подождите еще 1-2 часа
4. Проверьте статус в Vercel Dashboard

### Проблема: "Invalid Configuration" в Vercel

**Решение:**
1. Проверьте что DNS записи добавлены правильно
2. Убедитесь что тип записи правильный (A или CNAME)
3. Проверьте что значение совпадает с тем, что показал Vercel
4. Подождите 15-30 минут и проверьте снова

### Проблема: Домен не открывается

**Решение:**
1. Проверьте что DNS записи активны в Selectel
2. Проверьте статус в Vercel (должен быть "Valid Configuration")
3. Очистите кэш DNS:
   ```bash
   # Windows
   ipconfig /flushdns
   
   # macOS/Linux
   sudo dscacheutil -flushcache
   ```
4. Попробуйте открыть в режиме инкогнито
